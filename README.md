# LTP-GUI

Web-интерфейс управления ONT на OLT Eltex LTP-4X/8X.

## Требования
- Windows 10/11 x64
- Python 3.11+
- Node.js 20+

## Первый запуск (разработка)
Двойной клик по `run_dev.bat`. Откройте http://localhost:5173
